# Netflix Data Dashboard

## 📌 Project Overview

This project analyzes the Netflix Movies and TV Shows dataset using Python.

The goal is to:
- Clean the dataset
- Perform Exploratory Data Analysis (EDA)
- Build an interactive Streamlit dashboard

---

## 🛠 Tech Stack

- Python
- Pandas
- Matplotlib
- Streamlit
- scikit-learn
- Git
- GitHub
